# Support

Start with the [documentation site](https://nix-forge.github.io/vpn-confinement/),
especially the [Transmission guide](site/src/content/docs/guides/transmission.md),
diagnostics guide, and threat model.

For a bug or a reproducible configuration problem, [open an issue](https://github.com/nix-forge/vpn-confinement/issues/new).
Include the commit or input revision, NixOS version, service and namespace
configuration, the command that failed, and the smallest useful log excerpt.
Never include WireGuard private keys, provider credentials, or private network
details.

Use [SECURITY.md](SECURITY.md) for suspected vulnerabilities. Do not disclose
security-sensitive details in a public issue.

This project does not provide VPN accounts, managed deployments, or anonymity
guarantees. Public, minimal reproductions are the best way to get help.
